# 济州现场地图 · jeju-cn-map

面向中国游客的济州「现场用」地图。免安装、简体中文、手机优先（390px 布局设计）。**第 2 版**：加入了给店员看的卡片、公交·售票处卡片，以及每个景点最近的公交站韩文名。

- 线上地址: https://spaltino.github.io/jeju-cn-map/
- 制作: 2026-11-17 · 数据确认日 2026-11-17

## 3 个标签

1. **地图·景点** — Leaflet + OpenStreetMap。17 个景点（机场／济州市／涯月·西部／东部／中文·西归浦），中文＋韩文名、开放时间、门票、交通、打车预估、**最近公交站（韩文实名＋中文名＋距离）**；每张卡片三个按钮：`给司机看`（全屏韩文大字＋韩文地址＋复制）、**`问公交`**（「这趟车到 XX 吗？」＋站名大字）、复制地址。
2. **出行** — 支付宝／微信扫码坐公交（全岛 868 辆，2024-08 起）、下车刷卡与换乘规则、票价表、机场→主要地区线路、出租车计价与预估、租车（中国驾照不可用）、给司机看的短语卡（12 张）、**公交·售票处现场卡片**（8 个目的地「这趟车到 XX 吗？」＋下车卡＋门票·牛岛船票卡，人数 1~4 可切换）。
3. **支付·贴士** — **给店员看的大字卡片（8 张）**：支付（支付宝/Zero Pay）、退税、辣度、打包、要水、推荐菜品、洗手间、收据/袋子；支付宝/微信适用场所与手续费、退税（即享/机场）、eSIM、紧急电话（1330 中文）。

右上角可在 中文 / 한국어 之间切换（韩国司机、店主用）。

## 全屏卡片的结构

点一下卡片 → 占满全屏：顶部是给对方的说明（中文 + 韩文提示），中间是**很大的韩文句子**，必要时第二行黄色大字给出替代表达（如「안 맵게」／「덜 맵게」，门票的「성인 2명」／「어른 두 장」），下面小字是中文原意，司机卡片另有韩文道路名地址和复制按钮。

## 技术

- 单文件 `index.html` + 本地托管 `leaflet.js`/`leaflet.css`（不用 CDN，中国大陆网络更稳）
- 无框架、无登录、无追踪、无 Google Fonts / Google Maps（Google 在中国大陆被墙）
- 地图瓦片：OpenStreetMap 标准瓦片，加载失败 6 次以上自动切到 OSM France HOT 瓦片；列表与卡片不依赖瓦片
- 数据来源：bus.jeju.go.kr（线路·票价·**정류소 검색 站名**）、제주관광협회 관광지요금표(2026-09-16)、서귀포시 e-Ticket、제주세계유산본부、한국관광공사 1330、Google Maps 路线（2026-11-17 查询）
- 公交站名的取法：以本页景点坐标为圆心，取 제주버스정보시스템 站名检索里 700m 内最近的实名站；若 1.6km 内存在与景点同名的站（例如 `성산일출봉입구`、`천지연폭포`、`매일올레시장 7번입구`），用那个站名。牛岛岛上没有登记公交站，改用 `성산항`（去牛岛的渡轮码头）。距离是直线距离（约），不是步行距离。
