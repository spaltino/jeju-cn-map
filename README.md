# 济州现场地图 · jeju-cn-map

面向中国游客的济州「现场用」地图第一版原型。免安装、简体中文、手机优先（390px 布局设计）。

- 线上地址: https://spaltino.github.io/jeju-cn-map/
- 制作: 2026-11-17 · 数据确认日 2026-11-17

## 3 个标签

1. **地图·景点** — Leaflet + OpenStreetMap。17 个景点（机场／济州市／涯月·西部／东部／中文·西归浦），中文＋韩文名、开放时间、门票、交通、打车预估；「给司机看」全屏韩文大字卡片＋韩文地址复制。
2. **出行** — 支付宝／微信扫码坐公交（全岛 868 辆，2024-08 起）、下车刷卡与换乘规则、票价表、机场→主要地区线路、出租车计价与预估、租车（中国驾照不可用）、给司机看的短语卡。
3. **支付·贴士** — 支付宝/微信适用场所与手续费、退税（即享/机场）、eSIM、紧急电话（1330 中文）。

右上角可在 中文 / 한국어 之间切换（韩国司机、店主用）。

## 技术

- 单文件 `index.html` + 本地托管 `leaflet.js`/`leaflet.css`（不用 CDN，中国大陆网络更稳）
- 无框架、无登录、无追踪、无 Google Fonts / Google Maps（Google 在中国大陆被墙）
- 地图瓦片：OpenStreetMap 标准瓦片，加载失败 6 次以上自动切到 OSM France HOT 瓦片；列表与卡片不依赖瓦片
- 数据来源：bus.jeju.go.kr、제주관광협회 관광지요금표(2026-09-16)、서귀포시 e-Ticket、제주세계유산본부、한국관광공사 1330、Google Maps 路线（2026-11-17 查询）
